## 官方规则摘要

《计算机软件著作权登记办法》要求提交申请表、软件鉴别材料和相关证明文件。一般交存的源程序和一种文档均为前、后各连续 30 页；不足 60 页时应全部提交。除特定情况外，源程序每页不少于 50 行，文档每页不少于 30 行。

最终提交前必须把申请人姓名、身份证明、开发完成日期、首次发表状态等真实信息补全，并确保软件名称和版本号在申请表、源程序页眉、用户手册和界面截图中完全一致。
