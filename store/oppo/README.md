### 应用介绍

Mealory 是一款私人、安静的饮食回忆日记。你可以用照片或文字记录每一顿饭，保存日期、时间、地点、同行者和备注，并通过日历、搜索与回忆重新发现过去的饮食时光。

Mealory 不需要注册账号，不含广告、内购或社交功能。记录和照片默认只保存在你的设备中；你可以随时导出开放格式的完整备份，也可以从备份恢复。应用不申请网络、定位、通讯录、相机或全相册读取权限。

## 审核补充说明

1. 本应用为完全离线的单机工具，无需账号或测试密码，安装后即可测试全部功能。
2. “拍照记录”通过 Android 系统相机完成，应用本身不申请 CAMERA 权限。
3. “从相册选择”使用 Android 系统 Photo Picker，只能读取审核人员主动选择的照片。
4. “导出完整备份”和“从备份恢复”使用 Android 系统文件选择器。
5. 所有记录与照片默认保存在应用私有目录；应用不接入广告、统计、推送、账号、支付或云存储 SDK。
6. 建议审核路径：首页右下角记录按钮 → 拍照/从相册选择/无照片补记 → 保存 → 日历/回忆/我的 → 数据与备份。
